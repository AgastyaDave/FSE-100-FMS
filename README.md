# FSE-100-FMS

## Project Overview

FSE-100-FMS is a rehabilitation-focused game designed to support stroke patients in their recovery by combining therapeutic exercises with engaging gameplay. The goal of this project is to help patients rebuild motor control, improve focus, and strengthen cognitive skills through interactive activities that feel less like traditional therapy and more like play.

This project is intended to provide a structured set of exercises that target different areas of rehabilitation, while encouraging patients to stay motivated and consistent in their recovery journey.

## Purpose

Stroke recovery often requires patients to practice multiple areas of improvement, including:

- hand-eye coordination
- reaction time
- attention and concentration
- fine motor control
- memory and cognitive recall

The game is designed to help address these needs through a set of short, focused activities that can be used as part of a rehab routine.

## Key Features

- Interactive rehabilitation gameplay designed for stroke recovery
- Three separate activities, each targeting a different rehabilitation goal
- Accessible, game-based structure to encourage patient engagement
- Focus on recovery through repetition, pattern recognition, and controlled movement
- Modular development approach, with each team member contributing one activity independently

## Activities

### 1. Catch the Koi

This activity focuses on improving reaction speed, visual tracking, and hand-eye coordination. Players must detect and respond to moving targets, helping rebuild attentional control and quick motor responses.

Purpose:
- improve reaction time
- support visual focus
- strengthen coordination between sight and movement

### 2. Stone Holes

This activity is designed to support precision, controlled movement, and patience. Players complete a task that requires careful aiming and placement, which helps reinforce focus and steadiness in movement.

Purpose:
- improve coordination and control
- encourage careful, deliberate movement
- build hand precision and targeting skills

### 3. Match the Memory

This activity focuses on cognitive recovery by testing memory, recognition, and attention. Players match patterns or cards to stimulate the brain and support memory retention and concentration.

Purpose:
- improve memory recall
- support cognitive exercise and focus
- strengthen attention and pattern recognition

## Team Contribution

This project is being developed by three contributors, with each member working individually on a separate activity:

- one teammate develops Catch the Koi
- one teammate develops Stone Holes
- one teammate develops Match the Memory

This division allows each activity to be built with a clear purpose while also creating a full game experience that combines different rehabilitation exercises into one project.

## Design Philosophy

The project aims to balance therapeutic value with enjoyable gameplay. Rather than creating a traditional game alone, the goal is to develop an experience that supports meaningful recovery while remaining engaging and approachable for patients.

## Current Status

This project is currently in the planning and development stage. The core concept and activity structure have been defined, and the team is moving toward building each rehabilitation activity independently before integrating them into a unified game experience.
